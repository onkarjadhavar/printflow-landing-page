# PrintFlow — QR-Based Smart Printing & Xerox Service

> Promotional landing page for the student-led startup **PrintFlow**, submitted as a college venture project by third-year Computer Science Engineering students at **Sanjay Ghodawat Institute, Kolhapur**.

---

## 🚀 Concept Overview

**PrintFlow** is a QR-based smart printing concept designed to simplify document printing for students, professionals, and local Xerox shop owners. Instead of dealing with manual file transfers, pen drives, and repetitive verbal instructions, users simply scan a counter QR code, configure their print settings online, and submit their order directly to the shop’s queue.

### Core Highlights:
- **Scan & Start:** Contactless QR code counter engagement with standard smartphone cameras. Zero app installation required.
- **Transparent Print Configuration:** Set page ranges, duplex (double-sided), color modes (B&W / Color), and copies directly from the browser.
- **Streamlined Shop Workflow:** Reduces counter congestion and repetitive communication for local printing businesses.

## 🛠️ Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/onkarjadhavar/printflow-landing-page.git
   cd printflow-landing-page
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
   The static production bundle will be generated in `dist/`.

---

## 🌐 Deploy to Vercel or Netlify

- **Vercel:** Import this GitHub repository into [Vercel](https://vercel.com). Vite presets are automatically detected (`npm run build` / `dist`).
- **Netlify:** Drag and drop the `dist/` folder to [Netlify Drop](https://app.netlify.com/drop) or link via GitHub.
